# Tropico-Eternal
Trópico Eternal es una página web que permite jugar directamente en el navegador un mod personalizado de Doom II, sin necesidad de instalar nada.  La página carga un motor de Doom (PrBoom-plus) compilado a WebAssembly, descarga los archivos del juego, y los inyecta en el motor para iniciar la partida dentro de un elemento
